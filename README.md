# Brain Tumor MRI Classification Using CNNs

## Project Overview
This project investigates the use of Convolutional Neural Networks (CNNs) for multiclass brain tumor classification using MRI scans.

Classes:
- Glioma
- Meningioma
- Pituitary Tumor
- No Tumor

## Dataset
Dataset source:
https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

## Project Structure
```text
notebooks/
models/
results/
src/
```

## Setup

Create virtual environment:

```bash
python -m venv venv
```

Activate:

Install requirements:

```bash

```
